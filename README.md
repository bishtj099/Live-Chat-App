Live Chat Application  
A real-time chat application built with modern web technologies, designed to provide seamless communication between users. This project includes features such as instant messaging, user authentication, and responsive UI for both desktop and mobile devices.

*Key Features*:

Real-time messaging powered by WebSockets

Clean and responsive user interface

Support for multiple chat rooms or private conversations

Scalable backend architecture for handling concurrent users

Tech Stack
Frontend: HTML, CSS, JavaScript 

Backend: Node.js 

Real-time Communication: Socket.IO / WebSocket
